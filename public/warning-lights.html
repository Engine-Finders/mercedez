Engine & Emissions Warning Lights

These are the most common Mercedes warning lights you'll encounter. Each one has a dedicated page with the specific meaning, common causes ranked by likelihood, real cost data and a clear verdict.

Engine Management Light

The most generic and most important warning - the ECU has logged a fault. Reading the code is the only way to know what it means.

Typical cost: £90–£5,800 depending on cause

DPF Warning Light

Diesel particulate filter - a common Mercedes diesel issue. Urban driving is the main cause, and ignoring it can be expensive.

Typical cost: £300–£1,800

AdBlue Warning

Mercedes AdBlue system fault - often a failed NOx sensor, heater, or pump. You'll get a countdown before the car refuses to start.

Typical cost: £400–£1,500

Glow Plug Light

Flashing or staying on - the glow plug system has a fault. Usually one or more glow plugs have failed, but sometimes it's the relay or controller.

Typical cost: £150–£600

Limp Home Mode

Restricted performance - the ECU has cut power to protect the engine or emissions system. The stored code tells you why.

Typical cost: £90–£5,800

For a complete list of engine-specific symptoms, see the symptom index or the fault code directory.

Fluids & Temperature Warning Lights

These warnings relate to oil, coolant and battery - stopping or acting immediately can save the engine from catastrophic damage.

Oil Pressure Warning

Low oil pressure - stop the car immediately and check oil level. Driving with this light on can destroy the engine in minutes.

Severity: Catastrophic

Coolant Temperature Warning

Engine overheating - stop safely and check coolant level. A common cause is a failed water pump or coolant leak.

Typical cost: £400–£1,200

Battery Warning

Charging system fault - the alternator is not charging the battery. The car will run on battery power until it dies.

Typical cost: £400–£800

Drivetrain & Suspension Warning Lights

Mercedes drivetrain and suspension warnings - transmission, Airmatic and 4MATIC system faults. These can be expensive, so early diagnosis matters.

Transmission Fault Warning

Mercedes 7G-Tronic or 9G-Tronic transmission fault - often valve body or conductor plate failure. Get the code read.

Typical cost: £800–£3,500

Suspension Fault Warning

Airmatic suspension system fault - compressor, valve block or air spring failure. Common on E-Class, S-Class and GLE.

Typical cost: £400–£2,200

Frequently Asked Questions

How do I know which Mercedes warning light I have?

This index lists every warning light page we've built. If you don't see your exact light here, use the Diagnostic Wizard - it will ask you what you're seeing and where it's appearing, and suggest the most likely pages.

Is a Mercedes engine warning light always expensive?

It can be a £90 fuel filter or a £5,800 timing chain - the message itself tells you nothing about the cost. That is why we always recommend reading the fault code before accepting any quote. See our fault code directory to look up what your specific code means.

Can I drive with the Mercedes DPF warning light on?

If the light is amber and the car is not in limp mode, a sustained motorway run may clear it. If it's flashing or you're in limp mode, have it diagnosed. Ignoring a DPF warning can lead to a full DPF replacement or, in some cases, engine damage.

How much does it cost to replace a Mercedes engine after a catastrophic warning?

Recon supply costs for Mercedes engines start at £1,800 for an OM651 and can exceed £10,000 for a V8 AMG engine. Full engine replacement costs by engine code are on the replacement cost by engine code page.
